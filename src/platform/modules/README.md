# Design Studio modules

Modules provide capabilities. Each module's README explains its purpose and technical contract; `context/` holds additional knowledge and `skills/` holds relevant task procedures. Not every module needs a skill.

- [Prototypes](prototypes/README.md)
- [Systems](systems/README.md)
- [Canvas](canvas/README.md)
- [Documents](document/README.md)
- [Diagrams](diagrams/README.md)
- [Documentation](documentation/README.md)
- [Views](view/README.md)
- [Text files](text/README.md)

Read the platform's [module contract](../context/modules.md) before changing packaging, registration, dependencies, or lifecycle behavior. Enabled declarations determine availability; files alone do not enable a capability.
