## When to use

Use a dialog when a task needs a decision or a short piece of input before it can continue. Don't use one for information that could sit on the page.

`DialogContent` defaults to `size="sm"`. Use `size="lg"` for longer content or multiple decision buttons. Both sizes fit narrow screens; footer actions stack on mobile and wrap when needed.
