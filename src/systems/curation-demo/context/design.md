# Ticket triage

This is a demo specification, not supplied company brand guidance.

- Use the selected shadcn Base UI Nova preset, violet accents, Geist typography, and large corners.
- Support light and dark modes using the preset's semantic colors.
- Keep the dashboard compact: 28px page titles, 14px body text, 36px default buttons and inputs, and 16px between cards.
- Show an inbox with search, ticket status filtering, and a ticket details dialog with a Resolve action.
- Use text labels for ticket status. Keep keyboard focus visible and all popup surfaces inside this system's theme.
- Use synthetic ticket data. No external services or account integration.
