## When to use

Use tooltips for short explanations, keeping essential information visible. Compose `TooltipProvider`, `Tooltip`, `TooltipTrigger`, and `TooltipContent`. The trigger uses Base UI’s `render` prop for a focusable control.

The popup uses `usePortalContainer()` to stay within the owning theme and color mode.

See [source and adaptations](/systems/v4576ka1mbpbqdp1/context/library).
