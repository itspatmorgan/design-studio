## When to use

Use the default variant for the main action and outline for alternatives. Use `onClick` for actions and `disabled` for unavailable controls.

For navigation, use a plain anchor with `buttonVariants`. This keeps link semantics. Render icons as children. Sizes are `sm`, `default`, and `lg`; variants are `default`, `outline`, `ghost`, and `link`.
